## 2024-05-22 - Dashboard Empty State
**Learning:** Empty states in data-heavy dashboards (like "MOUNTED_DATABASES") are critical for user orientation. The "Neon" theme requires specific iconography and messaging (e.g., "NO_DATABASES_DETECTED") to maintain immersion.
**Action:** Always check list views for empty states and match the app's thematic language (e.g., "SEQUENCE", "PROTOCOL") when adding new UI text.
