# Light Novel NLP

## Обзор Проекта

**Light Novel NLP** — это комплексная система для автоматизированного анализа, обработки и перевода лайт-новел с использованием современных технологий обработки естественного языка (NLP) и больших языковых моделей (LLM), в частности Google Gemini.

Проект состоит из производительного Backend API на FastAPI и интерактивного Frontend на React. Система позволяет управлять проектами переводов, автоматически извлекать глоссарии, анализировать текст на наличие имён собственных и терминов, а также выполнять контекстно-зависимый перевод.

## Основные Возможности

### 1. Управление Проектами
- Создание и настройка проектов для каждой лайт-новеллы.
- Загрузка исходных текстов (поддержка .txt, .epub и других форматов).
- Отслеживание прогресса анализа и перевода по главам.

### 2. NLP Анализ и Глоссарий
- **Извлечение сущностей**: Автоматическое выделение имен персонажей, локаций, организаций и артефактов с помощью LLM.
- **Генерация Глоссария**: Создание структурированного глоссария для соблюдения консистентности перевода.
- **Редактирование**: Возможность ручной правки и дополнения глоссария.

### 3. Интеллектуальный Перевод
- **Контекстный перевод**: Использование собранного глоссария при переводе для сохранения точности терминов.
- **Поддержка стилей**: Адаптация стиля перевода под жанр произведения (фэнтези, научная фантастика и т.д.).
- **Многопоточность**: Параллельная обработка глав для ускорения работы.

### 4. Пакетная Обработка
- Фоновое выполнение задач через Celery и Redis.
- Поддержка длинных очередей задач без блокировки основного интерфейса.
- Механизмы повторных попыток (Retry) для обработки сбоев API.

## Технический Стек

### Backend
- **Язык**: Python 3.10+
- **Фреймворк**: FastAPI
- **База Данных**: PostgreSQL (с использованием SQLAlchemy 2.0+ и Alembic для миграций)
- **Очереди задач**: Celery + Redis
- **AI/LLM**: Google GenAI (Gemini Flash models)
- **Контейнеризация**: Docker & Docker Compose

### Frontend
- **Фреймворк**: React 18
- **Сборщик**: Vite
- **Маршрутизация**: React Router v6
- **API Клиент**: Axios
- **Стилизация**: CSS / Styled Components (предположительно)

## Архитектура

Система построена на микросервисной архитектуре, где Backend и Frontend разделены и общаются через REST API.

1.  **FastAPI Server**: Принимает запросы от Frontend, управляет данными в PostgreSQL и ставит тяжелые задачи (анализ, перевод) в очередь Redis.
2.  **Celery Worker**: Забирает задачи из Redis и выполняет их асинхронно, обращаясь к Google Gemini API для обработки текста.
3.  **PostgreSQL**: Хранит информацию о проектах, главах, глоссариях и статусах задач.
4.  **Frontend**: Предоставляет удобный интерфейс для взаимодействия с системой.

## Установка и Запуск

### Предварительные требования
- Docker и Docker Compose
- API Key от Google Gemini

### Запуск через Docker Compose

1.  Клонируйте репозиторий:
    ```bash
    git clone <repository-url>
    cd lightnovelnlp-1
    ```

2.  Создайте файл `.env` в корневой директории (используйте пример ниже).

3.  Запустите контейнеры:
    ```bash
    docker-compose up --build
    ```

4.  Приложение будет доступно по адресам:
    - **Frontend**: http://localhost:3000
    - **Backend API Docs**: http://localhost:8000/docs

### Конфигурация (.env)

Создайте файл `.env` в корне проекта и в папке `backend/`:

```ini
# Database
POSTGRES_USER=postgres
POSTGRES_PASSWORD=postgres
POSTGRES_DB=ranobe
DATABASE_URL=postgresql+psycopg2://postgres:postgres@postgres:5432/ranobe

# Redis
REDIS_URL=redis://redis:6379/0

# Google Gemini API
# Можно указать несколько ключей через запятую для распределения нагрузки
GEMINI_API_KEYS_RAW=your_api_key_1,your_api_key_2
GEMINI_API_LIMIT_PER_KEY="gemini-3-flash-preview=18, gemini-flash-latest=18"

# Environment
ENVIRONMENT=development
BACKEND_PORT=8000
FRONTEND_PORT=3000
ALLOWED_ORIGINS_RAW=http://localhost:3000,http://localhost:5173
```

## API Документация

Полная документация API доступна в Swagger UI после запуска сервера:
[http://localhost:8000/docs](http://localhost:8000/docs)

Основные эндпоинты:
- `GET /projects`: Список проектов
- `POST /projects`: Создание нового проекта
- `POST /processing/analyze/{chapter_id}`: Запуск анализа главы
- `POST /translation/translate/{chapter_id}`: Запуск перевода главы
- `GET /glossary/{project_id}`: Получение глоссария проекта
